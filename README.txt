Place your properly licensed local images in this folder.

Suggested filenames:
- serengeti-hero.jpg
- serengeti-game-drive.jpg
- serengeti-lion.jpg
- serengeti-elephant.jpg
- serengeti-zebras.jpg
- serengeti-migration.jpg
- serengeti-camp.jpg
- serengeti-sunrise.jpg

The current demo uses remote image URLs in index.html and css/style.css. To use local files, update each relevant src or background-image URL to point to ../img/filename.jpg (in CSS) or img/filename.jpg (in HTML).
